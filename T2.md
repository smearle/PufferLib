# Intrinsic rewards in PufferLib 5.0: T2, E3B, ICM, RND, E3B x RND

This branch adds intrinsic-reward exploration to the native CUDA trainer:
T2 (peer-channel Double Take, a world model trained on paired episodes) and
paper-faithful ports of the E3B-paper MiniHack baselines. Everything is
compiled in with `--t2` and selected at runtime with `[intrinsic] method`;
with the flag off the trainer is unchanged.

## Download and run a bounded example

Clone this branch, rather than the fork's default branch:

```sh
git clone --branch codex/t2-native --single-branch https://github.com/smearle/PufferLib.git
cd PufferLib
bash examples/intrinsic_smoke.sh t2 quadlab
```

Requirements: Linux, an NVIDIA GPU/driver, CUDA toolkit with `nvcc` (validated
locally with CUDA 12.8), a compatible C++ compiler, NCCL headers and
library, OpenGL development library, `curl` and `tar`. NCCL is linked even for
one GPU. `build.sh` also supports NCCL from the active Python environment's
`nvidia-nccl-cu12` package; its library directory must be on `LD_LIBRARY_PATH`.
The first build downloads Raylib. `ccache` is optional. The trainer itself has no Python runtime.

The example uses one GPU, 256 lanes and 2,097,152 environment transitions.
It is a smoke configuration, not the recipe used for reported learning curves.
Logs and policy/WM checkpoints go under `logs/` and `checkpoints/`. Keep the
checkout as the working directory so the binary can find its configuration.

```sh
bash examples/intrinsic_smoke.sh e3b craftax_classic
bash examples/intrinsic_smoke.sh icm trilab
bash examples/intrinsic_smoke.sh rnd quadlab
bash examples/intrinsic_smoke.sh e3b_rnd quadlab
```

Run the full native intrinsic test suite separately:

```sh
export PUFFER_OMP_LIB=-lgomp
./build.sh craftax_classic build/test_intrinsic --t2-test --float
./build/test_intrinsic
```

The lab headers, configurations and fixed 128-layout evaluation tables are
included in `ocean/trilab`, `ocean/quadlab` and `config`. They were copied byte
for byte from the validated lab environment sources. The trainer selects its
environment at build time; `./build.sh quadlab --t2 --float` builds `./puffer`
for QuadLab. Native intrinsic-suite validation covers Classic and NetHack;
lab environment parity and research learning evaluations are separate checks.

### Published source status

This branch contains the native T2/baseline implementation, recorder concurrency
repairs and complete active-history refresh beyond the GPU prefix capacity.
The exact core source was previously validated by 545,158 Classic and 20,171
NetHack checks. This publication reverified those source hashes; it did not
repeat those GPU suites or establish QuadLab learning recovery.

Later private pair-admission, per-update replay-refresh and full-history-gradient
experiments are not applied here. In particular, the current paired reservoir
can retry a rejected or evicted pair, peer encoder summaries are detached, and
replay caches refresh after the WM update block. Keep that revision distinction
when comparing published code with experimental results.

## Build and run

    export PUFFER_OMP_LIB=-lgomp             # gcc host compiler (LLVM: leave unset)
    ./build.sh craftax_classic --t2 --float  # float32 build (recommended)
    ./puffer train --intrinsic.method=e3b    # or t2, icm, rnd, e3b_rnd
    ./build.sh craftax_classic build/test_intrinsic --t2-test --float && ./build/test_intrinsic
    ./build.sh nethack --t2 --float          # NetHack (see below)

Without `--float` the trainer runs bf16 like upstream; intrinsic likelihoods
and distances then come from bf16 activations and the finite-difference
gradient tests are skipped.

## Methods

All bonuses land on the rollout row of the successor observation, the row
PufferLib credits to the action, scaled by the method's `coef`, then pass the
trainer's [-1, 1] reward clamp, which is TorchBeast's reward clipping.
`[intrinsic] intrinsic_only = 1` replaces the env reward instead of adding.

| method | bonus for (s_t, a_t) | training | normalization (`normalize`) |
|---|---|---|---|
| `e3b` | `phi(s_t)^T C^-1 phi(s_t)`, episodic Gram matrix of inverse-dynamics features, ridge 0.1, Sherman-Morrison update, zero on an episode's first step, reset when the transition terminates | inverse-dynamics loss on the encoder | `torchbeast`: the released running-std quirk (8-lane learner batches, count += T per batch) |
| `icm` | `\|\| phi(s_{t+1}) - f(phi(s_t), a_t) \|\|_2` | forward (1.0) and inverse (0.1) losses on the encoder, TorchBeast reductions | `none` |
| `rnd` | `\|\| predictor(s_{t+1}) - target(s_{t+1}) \|\|_2` | mean L2 summed over the unroll | `none` (coef 0.001) |
| `e3b_rnd` | `e3b_t * rnd_t` | both above | `torchbeast` on the product |
| `t2` | `clip((q_ctrl - q1) / ln 2, 0, cap)` from the world model (below) | peer-or-self likelihood training | reward_scale |

The feature learner (E3B, ICM) and both RND networks reuse the env's own
encoder architecture (linear by default, the env's custom CUDA encoder when
it defines one) as separate instances, followed by a linear feature head
(`feature_dim`, optional LayerNorm), a two-layer inverse-dynamics head over
`[phi(s); phi(s')]` with one softmax per action head, and for ICM a forward
model over `[phi(s); onehot(a)]`. Multi-head action spaces mask heads a verb
does not consume (NetHack). Optimizers: Adam or RMSProp with TorchBeast
defaults (lr 1e-4, eps 0.01, alpha 0.99, clip 40), one step per
`batch_rows` transitions (default 8 lanes x 80 unroll), one pass per epoch.
Sources: `src/baselines.cu`; contracts as in infogain-world-models'
`jax_e3b.py` / `jax_rnd.py` / `intrinsic_rewards.py`.

## T2

Every rollout step scores the transition (o_t, a_t) -> o_{t+1} under the
world model (WM) weights frozen for that rollout:

    q_ctrl = -log p(tok(o_{t+1}) | h_t, support = prefix through (o_{t-1}, a_{t-1}) + (o_t, PAD))
    q1     = -log p(tok(o_{t+1}) | h_t, support = prefix through (o_t, a_t) + (o_{t+1}, PAD))
    r_t    = clip(reward_scale * (q_ctrl - q1) / ln 2, 0, reward_scale * reward_cap)

h_t is a streaming minGRU encoding of the lane's episode; tok() is the env's
byte codec. The WM trains on a reservoir of complete episodes: half the rows
use the causal self prefix as support (the scoring control), half the
partner lane's trial of the same reset world (peer support). After each
training epoch, lane and reservoir states are re-encoded under the new
weights (`t2.reencode = 1`), so stored prefixes stay literal encodings.
`t2.max_episode` bounds the GPU replay prefix, not the scoring history or
environment episode. Longer active episodes retain their raw token/action
suffixes on the CPU and replay them in bounded GPU chunks after WM updates.
CPU history storage and re-encoding time grow with active episode length;
suffix storage is released at terminal reset. Replay sampling and peer summaries
retain the configured GPU prefix. Episodes are neither truncated nor reset at
that boundary.
Checkpoints: `<step>.bin.t2` (WM master weights and Adam state),
`<step>.bin.ir` for the baselines.

## Env contract (pufferenv.h)

Optional, per env header:

- `#define PUF_T2_TOKENS n` and `void puf_t2_tokens(Env*, unsigned char* out)`:
  a compact byte encoding of the observation for T2's likelihood target.
  Without it every observation value is quantized to one byte.
- `#define PUF_T2_PAIRED 1` once `puf_reset` seeds reset-persistent content
  from `puf_t2_world_seed(env->rng, episode, salt)` and dynamics from
  `puf_t2_dyn_seed(...)`; `env->rng` is the lane index the trainer assigns,
  `episode` counts that lane's resets, `salt` is `[env] t2_seed` (set from
  `base.seed` for T2 runs). Lanes 2k and 2k+1 then replay the same worlds.

Implemented for craftax_classic (114 lossless tokens; world/dynamics RNG
split) and nethack (223 tokens: 9x9 glyph crop, 16 status bytes, 24 message
bytes, inventory class counts, 3 state bytes; partner lanes boot from one
core seed and one level-generation seed through fast-nle, then switch to
lane-specific core/display streams with `nle_set_seed`).

## NetHack

`./build.sh nethack` clones and builds fast-nle; it needs cmake >= 3.28,
flex, bison and m4 on the PATH (no root: `pip install --user cmake`, and the
Ubuntu flex/bison/m4/libsigsegv2 packages unpacked with `dpkg -x`). The
NetHack encoder's decoder-key gradient wiring is now per instance, so the
intrinsic feature nets can hold their own NetHack encoders. T2 conditions
on all 20 action heads with unused heads read as PAD.

## Tests

`tests/test_intrinsic.cu` runs on the real trainer: env codecs and pairing
(craftax_classic and nethack), the T2 head and gate kernels against
references, the literal control prefix, re-encoding exactness, window
gathers, finite-difference gradients of the WM, the E3B step against an
explicit inverse, the TorchBeast normalizer against its formula, feature
learner and RND gradients, and a smoke of every method through rollouts,
PPO with intrinsic rewards, and intrinsic training.

## Deviations from the reference JAX T2

minGRU encoder instead of the nonlinear GRU; position-factored likelihood
head instead of the autoregressive attention decoder; truncated BPTT window
from stored (re-encoded) states instead of full-episode gradients; cached
peer summaries, detached; large-batch few-step Adam. The reward definition,
support constructions and terminal masking are preserved.

The successful JAX Cache32/direct-summary experiment also differs from this
native head: its 16 summaries are query-dependent attention reads over full
support and causal query histories. They are not 16 final recurrent states.
This branch's head receives one query endpoint and one support endpoint.
An equal reward formula does not establish equal learned information gain.

The lab benchmark sources provide a runnable environment, not a release of
archived trained policies or a claim that the C agent matches JAX performance.
