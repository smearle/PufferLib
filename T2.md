# T2 in PufferLib 5.0

T2 (peer-channel Double Take) is an intrinsic reward from a world model (WM)
trained on paired episodes. This branch adds it to the native CUDA trainer as
`src/t2.cu`, compiled in with `--t2` and switched on with `[t2] enabled = 1`.
Everything else in the trainer is unchanged when the flag is off.

## Build and run

    export PUFFER_OMP_LIB=-lgomp            # gcc host compiler (LLVM: leave unset)
    ./build.sh craftax_classic --t2 --float # float32 build (recommended for T2)
    ./puffer train --t2.enabled=1 --vec.total_agents=2048 --vec.num_buffers=4
    ./build.sh craftax_classic build/test_t2 --t2-test --float && ./build/test_t2

Without `--float` the trainer runs bf16 like upstream; T2 then computes its
likelihoods from bf16 logits, and the finite-difference gradient test is
skipped. `--t2` without `--float` compiles and trains.

## What runs where

Rollout (worker threads, one per vec buffer, after `puf_step` + upload):

1. `puf_t2_tokens` (or the generic byte quantizer) encodes o_{t+1} on the CPU.
2. One minGRU step encodes (o_t, a_t) into the lane's query state; two more
   steps from the stored states encode the supports (o_t, PAD) and (o_{t+1}, PAD).
3. The position-factored head scores tok(o_{t+1}) under both supports;
   reward = clip(scale * (nll_ctrl - nll_1) / ln 2, 0, scale * cap) is written
   on the rollout row of o_{t+1}, masked when o_{t+1} starts a new episode.
4. (tok_t, a_t, state_t) is appended to the lane's episode record; completed
   episodes move to a reservoir keyed by (pair, episode) so partner trials
   of the same world sit in sibling slots.

Train (main thread, after the PPO epoch, workers idle):

- `t2.wm_steps` Adam steps of `t2.wm_batch` rows sampled from the reservoir.
  Each row replays a `t2.bptt_window` window of one episode through the
  encoder (query sequence and self-support sequence), takes the peer summary
  of the partner episode with probability `t2.peer_prob` when present, and
  minimizes the token NLL of the successor. Rewards for the trained slot are
  added into the PPO reward tensor before the reward clamp.

Checkpoints: `<step>.bin.t2` holds fp32 master weights and Adam moments.
Logs: `env/t2_*` (reward, nll_ctrl, nll_1, cap_frac, wm_loss, peer_frac,
reservoir, episodes) and `perf/t2_rollout`, `perf/t2_train`.

## Env contract (pufferenv.h)

Optional, per env header:

- `#define PUF_T2_TOKENS n` and `void puf_t2_tokens(Env*, unsigned char* out)`:
  a compact lossless byte encoding of the observation (craftax_classic: 114
  bytes for 1345 floats). Without it every observation value is quantized to
  one byte (exact for binary/small-integer values).
- `#define PUF_T2_PAIRED 1` once `puf_reset` seeds reset-persistent content
  from `puf_t2_world_seed(env->rng, episode, salt)` and dynamics from
  `puf_t2_dyn_seed(...)`, where `env->rng` is the lane index the trainer
  assigns, `episode` counts that lane's resets, and `salt` is `[env] t2_seed`
  (the trainer sets it from `base.seed`). Lanes 2k and 2k+1 then replay the
  same worlds with independent randomness. Without it T2 trains from
  self-prefix support only.

`ocean/craftax_classic/craftax_classic.h` implements both in about 60 lines.

## Deviations from the reference JAX recipe

The reference (infogain-world-models `t2_peer_self.py` / `t2_execution.py`)
uses a nonlinear GRU with full-episode gradients and a two-layer
autoregressive byte decoder with attention over the whole history. This port
keeps the reward definition, the peer-or-self support construction, the exact
self-prefix + PAD semantics, terminal masking and frozen-per-rollout scoring,
and changes the model for speed:

- minGRU encoder (PufferLib's kernels) instead of the nonlinear GRU;
- position-factored MLP likelihood head (no attention) instead of the
  autoregressive decoder: p(tok_p | q_t, s) with per-position bias;
- truncated BPTT window from stored (rollout-time) states instead of
  full-episode gradients;
- peer support is the partner's cached final encoder output, detached;
- large-batch, few-step Adam instead of 256 steps per 15,872 frames.

Measured on one RTX 4090, craftax_classic, float build, 2048 lanes: about
246k agent steps/s with T2 (1.9M without), of which WM training is roughly
60% of wall time, rollout scoring 15%, PPO 8%.
